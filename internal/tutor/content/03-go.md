# Go at the prompt

The same prompt is a Go interpreter, and state persists: variables,
functions, types and imports carry across inputs exactly as if the lines
were a script being evaluated one at a time.

## step: declare
Bind a value with `:=`, as in any Go function body.

Make `count` hold 3.
---
verify: var count type=^int$ value=^3$
hint: `count := 3`
solution: count := 3

## step: inspect
`?name` inspects a live variable: its type, and its value
pretty-printed — slices and maps as aligned tables, structs by field.

It is a prompt convenience, not language: scripts never see it, and it
never lands in your session history.

Inspect `count`.
---
verify: used-construct ^\?count$
verify: var count value=^3$
hint: A bare question mark in front of the name.
hint: `?count`
solution: ?count

## step: arith
Go expressions are Go expressions.

Print 42, computed from `count` rather than typed.
---
verify: used-construct count
verify: output-regexp (?m)^42$
hint: `fmt.Println` writes to the session's stdout, so its output pipes
hint: and redirects like any command's. 3 × 14 is 42.
hint: `fmt.Println(count * 14)`
solution: fmt.Println(count * 14)

## step: slice
`glob(pat)` is one of the pre-declared helpers: filename expansion from
Go, returning a `[]string` (empty, never nil-surprising, when nothing
matches).

Bind the Go files in this directory to `files`.
---
verify: var files type=^\[\]string$ value=greet\.go
hint: `glob` takes the same pattern the shell would.
hint: `files := glob("*.go")`
solution: files := glob("*.go")

## step: loop
Now a real block. Type the opening line and press Enter: the prompt
becomes `...`, a breadcrumb under it names the construct you are
inside, and each new line is auto-indented two spaces per open block.
Typing `}` first on a line dedents it, gofmt-style. The unit runs when
the braces balance.

Print each name in `files`, one per line.
---
verify: used-construct range
verify: output-regexp (?s)greet\.go.*main\.go.*util\.go
hint: `for _, f := range files {` — then the body, then `}`.
solution:
  for _, f := range files {
      fmt.Println(f)
  }

## step: iff
Go has no ternary, and scripts want one, so grsh pre-declares
`iff(cond, a, b)`. It is lazy like a real `?:` — only the taken branch
evaluates, so `iff(len(xs) > 0, xs[0], "none")` is safe on an empty
slice.

Print `plenty` if there are more than two Go files, otherwise `few` —
in one line.
---
verify: used-construct iff\(
verify: output-regexp (?m)^plenty$
hint: `iff(len(files) > 2, ...)`
hint: `fmt.Println(iff(len(files) > 2, "plenty", "few"))`
solution: fmt.Println(iff(len(files) > 2, "plenty", "few"))
